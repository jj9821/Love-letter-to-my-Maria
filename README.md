# A Love Letter for Maria Mathew

A cinematic, interactive digital love letter addressed to **Maria Mathew** from **Joel**.

Built to evoke the intimate, tactile feeling of receiving and unsealing a physical vintage letter rather than viewing a modern webpage.

## ✨ Experience

- **Aged Parchment Envelope**: Realistic paper texture, natural shadows, and subtle wear.
- **Vintage Stamp & Postal Cancellation**: Perforated botanical stamp with custom postmark lines.
- **Handcrafted Wax Seal**: 3D crimson wax seal that breaks when tapped.
- **Cinematic 3D Unfolding**: The envelope opens in perspective and the stationery slides out, unfolding along natural creases.
- **Live Fountain Pen Inking**: Progressive handwriting animation at a deliberate, slow, emotional reading pace with natural punctuation pauses.
- **Soundtrack**: Custom soundtrack starts automatically the instant the letter is opened, accompanied by gentle physical paper rustles.
- **Reading Controls**: Floating brass controls to play/pause music, mute/unmute audio, pause reading, skip to end, or re-seal the envelope.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & CSS 3D Perspective Transforms
- **Audio**: HTML5 Audio & Web Audio API

## 🚀 Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the letter.

To customize or update the letter text, edit `data/letter.ts`.
